# 11项白板动画目录

本插件维护以下11项方法。效果属于基础机制或布局组合，不保证每项都是互不相关的原子特效。真实API见[输入输出](INPUT-OUTPUT.md)，每项详细说明链接包含必需/可选输入和限制。

| ID / 动画 | 使用场景 | 画面结果 | 详细合同 |
|---|---|---|---|
| D01 · 轮廓逐笔→整组填色 | 把一个完整对象的形成过程讲清楚。 | 绘制计划、完成对象和连续手部轨迹。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d01.md) |
| D02 · 同画布逐项累积 | 同一话题逐步增加信息。 | 保留旧内容的累积画布。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d02.md) |
| D03 · 现成图固定位置渐入 | 展示已画好的图、照片或资料。 | 完整图的平稳入场。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d03.md) |
| D04 · 整板上移清屏 | 从一个话题切换到下一组画面。 | 清晰切换后的新画布状态。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d04.md) |
| D05 · 整板左移腾出空间 | 同一主题需要向右续画。 | 保留关系的横向续画。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d05.md) |
| D06 · 手掌摆放现成资料图 | 用自然手势将完整资料放上画布。 | 停稳的完整资料与自然退场。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d06.md) |
| D07 · 前景图渐入覆盖底图 | 在已有资料上补充或对照。 | 可回看的层叠关系。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d07.md) |
| D08 · 字形轮廓描绘→字内填色 | 突出关键词，同时展示字形生成。 | 完成字形与字内填色。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d08.md) |
| D09 · 对象先行→分支箭头手绘 | 表达从一个对象到多个对象的有向关系。 | 可替换对象的有向关系图。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d09.md) |
| D10 · 真实已完成画布纵向拉远总览 | 结尾回顾已经讲过的画面结构。 | 全部真实历史画面入镜的总览。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d10.md) |
| D11 · 字形轮廓描绘→手绘背景扫色 | 突出标题或关键词背后的色块。 | 背景着色、字内保持纸白的标题。 | [输入/输出/限制](../skills/whiteboard-video/references/effect-d11.md) |

图内文字、现成照片和真实手绘可共同使用，但必须如实区分机制。没有额外的“十stage巡览”效果。总览只引用已经完成的画面；不附带第三方参考视频或把参考片烧入输出。

Whiteboard Animation名称与混合手绘/现成图的背景阅读：[VideoScribe白板动画介绍](https://www.videoscribe.co/en/whiteboard-animation/) · [不同动画方式组合](https://blog.videoscribe.co/how-to-use-different-animation-styles-together-in-one-video)。本插件是独立Remotion实现，不宣称与这些产品兼容或由其提供。
