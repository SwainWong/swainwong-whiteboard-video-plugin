# 白板动画风格与稳定性 Harness

本规则适用于独立白板动画插件。用户已经授权维护本插件规则，不需要逐条再批准；具体作品的偏好与验收仍按实际反馈记录，不向其他视频插件自动传播。

## MUST

| ID | 必须做到 | 证据 |
|---|---|---|
| W01 | 对象先有明确文字语义；参考、运行资产、完成帧快照分开登记 | 输入与资产清单 |
| W02 | 成熟说明插画：结构与比例可信、轮廓一致、细节足以辨认 | 目标尺寸的过程与终态观察 |
| W03 | 绘画使用有序路径；笔尖与当前路径进度一致 | 路径顺序、绘制窗口 |
| W04 | 真实笔顺、字形描边、位图置入如实命名 | 路径来源和实际机制 |
| W05 | 按cue留阅读时间；超预算减少完整内容或换完整简化图 | 计划与截止时间、必需对象完整性 |
| W06 | 邻近绘制先排下一步，手连续移笔/保持/退出，接触点稳定 | 跨笔画及跨对象窗口 |
| W07 | 手掌推图使用校准照片质感手臂，停稳后分离 | alpha边界、锚点、入停退窗口 |
| W08 | 字内填色与背景扫色分开；颜色可配置，背景边缘自然但整齐，确定性不抖动 | 两色渲染与前中后帧 |
| W09 | 分支对象可以是图或照片；先端点对象后关系；遵守实际支持的方向/间距 | 可替换对象fixture与连线端点 |
| W10 | 总览仅纵向展示真实已完成stage；必须核对视频/帧/快照来源 | 快照manifest、哈希与源帧像素 |
| W11 | 最终所有stage边界入镜，最后stage到总览连续 | 世界边界和镜头变换、终态 |
| W12 | 运行验证、解码、像素观察、正常速度观感、实际口播同步、用户接受分开 | 当前输出身份绑定的报告 |

## MUST NOT

- 不从JPEG/PNG推断“已有真实笔顺”，不把生成成图冒充作画过程。
- 不因超预算留下半个必要对象，不无限提高笔速，不省略阅读时间掩盖不同步。
- 不用逐字透明度冒充手写，不把字幕层普通文字误标为被绘制内容。
- 不让手每画完一个对象都淡出、瞬移、离场再重新出现；真实段落结束可连续退场。
- 不把任意图片节点扩称“任意方向自动布线”；当前限制看实际接口。
- 不制造假stage、复制当前页或横向网格冒充纵向历史画布；不增加额外巡览配方。
- 不用文档存在、参数类型、导出成功或静帧充当观感或用户确认。

## 失败与复核

缺运行资产、缺有序路径、必需对象时间不足、节点布局不支持、快照来源不完整时，对应项目返回具体错误和最小修复。先完成不依赖缺口的准备工作；不以静默降级改变已选机制。

改文字、图形、布局、颜色或时序后，检查受影响的入场/绘制/保持/退场窗口；无关已验证效果不必全重渲。输入校验防止明显非法值，美术判断仍需看实际输出。声明“正常速度已看”必须实际连续播放；当前无音轨则不能声明口播同步通过。

## 长篇制作与发布补充

每次长篇制作同时执行 [Production harness](PRODUCTION.md)：逐句画面对照、有机无限画布、标志性对象、连续手部、实际口播对齐，以及品牌封面和发布文案。其检查项是制作/审核合同，不冒充已经实现的自动检测。
